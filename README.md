# LRC记事本

像记事本一样轻量的安卓小工具：点开 .lrc 文件就能看全文、能改、能存。

- 显示**原始全文**，包括行首 `[mm:ss.xx]` 和行内 `<mm:ss.xx>` 逐字标签，一个字都不加工
- 打开方式：在文件管理器 / 下载里点 .lrc 文件时可选本 App；在 App 里点「打开」也能选文件（.txt 也支持）
- 编辑后「保存」写回原文件（UTF-8）；「另存为」存到新文件；「新建」开空白页
- 有未保存修改时，标题带 ●，新建 / 打开 / 返回退出都会先提醒
- 读取编码：先按 UTF-8，解不开自动按 GBK（老中文歌词文件常见）
- 带一个简单的「查找 / 下一个」
- **没有**播放、没有 MP3、没有歌词高亮、没有文件夹扫描，就是个记事本
- 无 INTERNET 权限，纯本地

包名：`com.dannycom888.lrcnotepad` · 与 MyLRC Auto / MySing / LRC 编辑器共用同一签名。

## 安装

从 GitHub Releases 下载 `LrcNotepad-1.0.0.apk`，在手机上点开安装（允许安装未知来源应用）即可。
